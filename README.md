#Контрольные вопросы

##1. С какого индекса начинается нумерация элементов массива?
- С нуля

##2. Какой последний допустимый индекс у массива длиной `Length`?
- Length - 1

##3. Почему в цикле пишут `i < array.Length`, а не `i <= array.Length`?
- Выйдет за предел массива и будет ошибка

##4. Когда удобнее использовать `for`, а когда `foreach`?
- for когда нужен доступ к индексам, а foreach когда нужно только значение элемента

##5. Почему изменение элемента массива внутри метода видно снаружи без `ref`?
- Используется не переменная, а ссылка на массив

##6. Почему при поиске максимума и минимума удобно начинать с `array[0]`, а не с `0`?
- Не пишем так, как может быть работа с отриц. числами  там ноль будет всегда больше или его не будет в массиве но по итогу условий будет выводить ноль

##7. Что означает запись `int[] numbers = [1, 2, 3]` и чем она отличается от старого варианта `int[] numbers = { 1, 2, 3 }`?
- Создаётся массив. Позволяет объявлять и заполнять массив в одной строке без явного указания типа элемента.
